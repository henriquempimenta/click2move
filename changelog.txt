Version: 0.1.15
Date: 2026-10-15
  Features:
    - Add a per-player "Disable on arrival" setting that turns Click2Move mode off after the last queued destination is reached.
    - Draw routes and numbered destinations on the map when remote view is zoomed out.
  Changes:
    - Spidertrons finish where their autopilot stops instead of within the vehicle proximity radius, and a spidertron remote command now takes over from Click2Move.
    - Detect flight from any armor that provides flight instead of only the base mech armor.
    - Translate the "No path found" message.
  Bugfixes:
    - Preserve newer Spidertron destinations and follow orders during route completion, cancellation, disconnect cleanup, and upgrades from older saves.
    - Rebuild destination markers for active flying routes when updating the mod.

Version: 0.1.14
Date: 2026-10-11
  Features:
    - Consume multiple already-passed waypoints on straight path sections using observed character and vehicle motion, including exoskeleton movement and Hovercraft drift.
  Changes:
    - Bound waypoint advancement per update and preserve pending motion evidence across save/load while retaining turns and final destination checks.
  Bugfixes:
    - Check character arrival every tick near the destination to prevent overshooting at larger update intervals, including powered mech armor flight.
    - Cancel stale routes and pending requests when the movement entity changes physical surface.
    - Ignore car passenger commands and clear routes on driver handoff without overwriting the new driver's input.
    - Choose the correct diagonal walking direction when horizontal and vertical distances are equal despite floating-point roundoff.

Version: 0.1.13
Date: 2026-10-01
  Bugfixes:
    - Keep braking at vehicle destinations until speed and scripted drift settle before advancing queued goals.
    - Handle Hovercrafts 2.1.4 New-mode braking impulses that cross zero or restart movement near rest.
    - Approach farther inside the destination radius after stopping short or overshooting to avoid repeated stops at the edge.
    - Account for harmless quantized Hovercrafts New-mode drift jitter when checking that a vehicle has settled.
    - Allow manual vehicle takeover in normal view while preserving movement during remote-view panning.
    - Preserve active routes and pending requests across save/load and configuration changes.
    - Clear all queued character destinations on manual takeover without interrupting remote-view panning.
    - Preserve flight queues and recompute ground paths after landing.
    - Measure stuck detection and recovery in game ticks and correct perpendicular character slides.
    - Recompute affected queued paths after a failed leg and stop input during disconnected-player cleanup.
  Changes:
    - Limit path prefetching, reuse persistent path rendering, and cache player settings.
    - Check Lua syntax, regression tests, and runtime packaging before publishing.
    - Package only an explicit allowlist of runtime files and preserve curated release notes.
